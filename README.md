## AI Policy
All of our code is reviewed by AI for obvious security/performance flaws. Some of us use AI agents(CC) to write code, while other's don't. While others may disagree, we find the difference in quality marginal enough to not care about (our own) AI PRs. Many of our PRs are AI generated as most of us are ESL. With that said, all of our code is read by at least one human, most of it read by at least a few of us. Somewhat hypocritically, we only plan on releasing rewrites/updates we make on open-source software, while keeping our own software closed-source. While this seems ironic, it is become very easy to simply replicate software by pointing an agent at an open-source codebase and letting it go nuts. This software is often buggy and unfinished, but still a genuine concern to the original software. Chambers has been a WIP since before OpenAI released ChatGPT, and we'd like to release it to the public, but we also want to know that it is our product, hence the above decision. Please don't try and reverse engineer anything we do release, we are lawyers :).
